This MATLAB script computes the final angular positions of the six servo motors for the RSS Stewart Platform using inverse kinematics. The homogeneous transformation matrix (HTM) is formulated based on the geometry and dimensions of the RSS Stewart Platform developed in this project. Because the HTM is specific to the platform's mechanical configuration—including the base and moving platform geometry, link lengths, and servo arrangement—it must be modified to suit other Stewart Platform designs.

The nonlinear inverse kinematics equations are solved using the Newton–Raphson iterative method to determine the required servo angles. The code is written in a MATLAB Coder-compatible format, allowing it to be automatically converted into C/C++ code. The generated code can then be deployed on embedded microcontrollers such as the Arduino or Teensy 4.1, enabling real-time execution of the inverse kinematics algorithm on the target hardware.
